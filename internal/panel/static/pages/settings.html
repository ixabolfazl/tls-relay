🛡️ Access & Security

Access Mode

Control who can connect through the relay. Changes take effect immediately — no restart required.

In Public mode, all connections are allowed (subject to blacklist). In User-based mode, only IPs of enabled registered users are permitted.

Unknown Domain Policy

Determines what happens when a connection arrives for a domain not in the domain rules list. Changes take effect immediately.

Allow: connections to unknown domains on allowed destination ports are relayed. Reject: connections to unknown domains are refused immediately.

DNS Passthrough for Unregistered IPs

When enabled, IP addresses that are not registered to any user can still resolve domains that are not in the relay domain rules. Applies a separate, stricter rate limiter. Changes take effect immediately.

Security note: Enabling this allows any IP to use the DNS service for non-relay domains. Restrict your resolver to trusted networks at the firewall level if you enable this.

Connection Limits

Set maximum allowed concurrent connections per client IP to prevent abuse while allowing multi-tab/multi-device browsing. Takes effect immediately.

Connections exceeding this limit from a single client IP will be rejected with rejected_limit status. Default is 200.

Admin Credentials

Change the administrator username and password. Changes take effect immediately.

Leave blank to keep the current username.

🌐 Network & Ports

Allowed Destination Ports

Hot-Reloadable

Permitted target ports for relayed connections (when policy is "Allow" or rule uses "all"). Takes effect immediately without restarting.

Connections targeting any port not in this list are rejected immediately. Default: 443, 8443, 2053, 2083, 2087, 2096, 9443.

Server Listen Ports

Requires Restart

Local network ports bound by the relay server. Changing these ports requires restarting the service to take effect.

Port(s) where TLS SNI relay listens for incoming client connections (default: 443).
Port(s) for HTTP relay, portal landing page, and admin panel dispatch (default: 80).

IP address or hostname and port of the SOCKS5 proxy server.

⚙️ General

Display Timezone

All timestamps in the admin panel will be displayed in this timezone. Changes apply immediately without a page reload.

Select the IANA timezone for timestamp display (e.g. Asia/Tehran, America/New_York).

Server Domain

Public domain name or hostname used for generated magic links, setup URLs, and client configuration. If empty, the server IP address is used automatically.

When configured, all magic links and client setup URLs use this domain. Schemes (http://, https://) and trailing slashes are automatically normalized. Leave empty to use the server IP address.

Admin Panel Path

Change the URL prefix for this admin panel. After saving, you will be redirected to the new path automatically.

Use / for root or a path like /admin. Leading slash is required.
— Read-only. To change the listen address/port, edit config.yaml and restart.

⚡ Service Control

Service Management

● Active

Control and restart the TLS Relay background service safely from the console.

— Uptime since last service start.

Restarting the service reloads all configuration files and binds newly configured listen ports. The process performs a graceful handover and automatically recovers within 2 seconds.

📜 Logging

Request Logging Settings

Enable or disable request logging and set auto-cleanup retention period.

Enter custom duration (e.g. 5m, 15m, 1h, 6h, 24h, 7d, 30d). Expired logs are purged automatically.

💾 Backup & Data

Export Configuration

Download a complete JSON export of all domain rules, global blacklist entries, and user accounts with registered IPs.

SQLite Database Backup

Download a raw point-in-time snapshot copy of the SQLite database file (.db). This creates an atomic, consistent backup without stopping the relay server.

Import Configuration

Restore domain rules, blacklist entries, and user accounts from a JSON export file. The entire payload will be validated first; if any entry is invalid, the import will be rejected with zero changes applied.
